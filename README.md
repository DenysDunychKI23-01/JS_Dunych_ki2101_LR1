## 📋 Виконані завдання

### Завдання 1
Створено список `<ul>`, який динамічно заповнюється літерами імені (**Денис**). При наведенні курсора миші (`mouseenter`) на будь-яку літеру виводиться діалогове вікно `alert` із цієї літерою.

### Завдання 2
Реалізовано функціонал введення студентів. Скрипт у циклі `while` запитує прізвища та імена через `prompt()` та одразу відображає їх у браузері. Робота циклу завершується, коли користувач натискає кнопку **"Скасувати" / "Відміна"**.

### Завдання 3
Створено кнопковий інтерфейс та контейнер `id="letters"`. При натисканні на кнопку для кожної літери прізвища (**Дунич**) генеруються окремі блоки `<div>`. Наведення на блок викликає `alert` із текстом *«Це літера [ ]»*. При повторному натисканні кнопки контейнер очищається.
